Layout — what I'd change

Same Graphite style as the app now; only the layout changes. Each option fixes something that showed up when the app ran: the filters take half the screen, free and busy rooms are mixed together, the user has to open a room to see when it's free, and on a phone the actions are far from the thumb.

A · Now boardB · Split viewC · Mobile flowD · Week grid

A · Now board my main recommendation for /rooms

One-line toolbarSearch + 3 compact filters on one row instead of a form with labels. The list starts ~150px higher.
Grouped by status"Free now" first, sorted by how long they stay free. Busy rooms below, dimmed.
Today at a glanceA small 08–20 strip per room: grey = class, green = the free window from now, white line = now.
